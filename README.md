# Paper Toss Office

> **[▶ Play the browser preview](https://trusegone.github.io/paper-toss-office/)** — play instantly on Android, iPhone, tablet, or desktop. No installation required.

A compact Java/libGDX arcade game, with a browser-playable version.

## Browser preview

Open the game directly in your browser: **[Play Paper Toss Office](https://trusegone.github.io/paper-toss-office/)**

- **Mobile:** use the on-screen aim and throw controls.
- **Desktop:** use W/S or Up/Down to aim, then hold and release Space to throw.
- If the page does not load, check the [GitHub Pages deployment status](https://github.com/TruSegone/paper-toss-office/actions).

## Run the desktop version

Install Gradle 8+ and a JDK (Java 17+), then run:

```powershell
gradle :desktop:run
```

The desktop game opens in a fixed 800 × 600 window.
